# neurarrow-ext

Extensions to the [neurarrow](https://github.com/clbarnes/neurarrow/) specification.

- [net.clbarnes.swc](./extensions/swc.md): extending skeletons for compatibility with the [SWC format](http://www.neuronland.org/NLMorphologyConverter/MorphologyFormats/SWC/Spec.html)
- [net.clbarnes.connector](./extensions/connector.md): a new schema for point annotations associated with connections

See also [TEMPLATE.md](./TEMPLATE.md) for defining your own extensions.
